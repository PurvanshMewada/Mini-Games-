HOLO ARCADE (Wordle + mini games) - runs offline in its own window, no tabs or address bar.

1. Unzip this folder anywhere and keep all the files together.
2. Start it:
   Windows: double-click Play-Wordle-Windows.bat
   Mac:     double-click Play-Wordle-Mac.command
            (first time: right-click, Open, then Open again)
   Linux:   run Play-Wordle-Linux.sh  (make it executable first: chmod +x Play-Wordle-Linux.sh)
3. It needs Edge, Chrome or Brave installed (Windows already has Edge).
   Your streak and settings are saved on this computer.

Desktop shortcut with the icon (Windows):
   Right-click Play-Wordle-Windows.bat > Show more options > Send to > Desktop (create shortcut).
   Then right-click the shortcut > Properties > Change Icon > Browse > Wordle-icon.ico.
